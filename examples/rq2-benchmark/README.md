# RQ2 contract examples

Small synthetic instances of the WP0 contracts. **Not benchmark gold**: the
wording and elements are illustrative only. Validated by
`tests/test_rq2_contracts.py`.

- `atom-set.example.yaml` — `RQ2AtomSet` (`schema/rq2_atom.linkml.yaml`), incl. one L4 counterfactual variant.
- `profile-delta.example.yaml` — `ProfileDelta` (`schema/profile_element.linkml.yaml`).
